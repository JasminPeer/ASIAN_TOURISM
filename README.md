## ⚙️ Prerequisites & Setup

### Requirements
- Basic familiarity with `JavaScript`
- Git installed on your local machine

### Installation Steps
```bash
# 1. Clone repository
git clone https://github.com/JasminPeer/ASIAN_TOURISM.git
cd ASIAN_TOURISM

# 2. Install dependencies
npm install

# 3. Run application
npm start
# or npm run dev
```
